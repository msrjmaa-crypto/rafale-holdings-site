画像の設置方法
====================

このフォルダに以下のファイル名で画像を置くと、サイト側の修正なしに
自動的に反映されます。読み込みに失敗した場合（ファイルが無い場合を含む）は、
必ず現在の黒×ゴールドのデザイン（グラデーション背景／アイコン）に
自動でフォールバックするため、レイアウトが崩れることはありません。

  img/logo.png           … 会社ロゴ（現在は仮ロゴ）。ヘッダー左上とトップの
                             ファーストビュー中央の【両方】がこの1ファイルを
                             参照しています。差し替えるだけで全ページに反映されます。
                             ※黒背景に載るため「ダーク背景用」（白背景を透過し、
                               RAFALE/HOLDINGSの文字を白系にした版）を推奨。
                               縦横比は自由（height/width autoで自動維持）、
                               推奨は透過PNG・長辺1000px程度・背景透過。
  img/hero-poster.jpg    … 任意：トップのファーストビュー背景（静止画）
  （img/representative.jpg … 代表写真は非掲載の方針となったため、現在は未使用です。
    MESSAGEセクションは余白とタイポグラフィのみで構成しています）
  img/ogp.jpg             … SNSでシェアされた際のサムネイル画像
                             （index.html の og:image / twitter:image が参照）
  img/favicon-32.png
  img/favicon-16.png
  img/apple-touch-icon.png
  img/icon-192.png
  img/icon-512.png        … ブラウザタブ・スマホのホーム画面アイコン用
  img/brand-sakura-logo.png … BRANDSセクション「SAKURA Poker Lounge」のロゴ

img/brand-sakura-logo.png は SAKURA Poker Lounge の正式ロゴです
（公式サイト sakura-poker.jp で使用しているものと同一・背景透過PNG・1400×556）。
差し替えるときは同じファイル名で上書きし、index.html の src に付けている
「?v=」の数字を1つ上げてください（/img/* は1週間キャッシュされるため）。
正方形・横長どちらの比率でも object-fit: contain によりロゴ全体が
必ず表示され、切れることはありません（枠に対して余白ができるだけです）。
推奨: 長辺1000px程度、背景透過PNG（黒背景のままでも問題ありません）。

新しいブランドを追加する場合は、index.html の #brands 内にある
<article class="brand-card"> ブロックをコピーして .brand-grid の中に
追加してください。PC横並び／タブレット2列／スマホ1列は自動で対応します。

上記のうち ogp.jpg / favicon-*.png / apple-touch-icon.png / icon-*.png は、
ロゴマーク（ゴールドの菱形）を使った既定デザインとして最初から用意済みです。
そのままでも使用できますが、正式なロゴが決まり次第、同じファイル名で
上書きすれば自動的に差し替わります（サイズ・比率は上記の推奨スペックに
合わせてください）。

レイアウトが崩れない理由
  - hero-poster.jpg は画面いっぱいに object-fit: cover で自動トリミングされます。
    どんな縦横比の写真を置いても、周囲が切り取られるだけで、
    文字やボタンの位置がずれることはありません。
  - representative.jpg も同様に object-fit: cover で円形フレームに
    自動トリミングされます。正方形でなくても問題ありません。
  - どちらも「画像が読み込めたら少しずつフェードインする」実装になっており、
    ファイルが無い間は元のデザイン（グラデーション／アイコン）がそのまま
    表示され続けます。壊れた画像リンクが表示されることはありません。

推奨スペック
  hero-poster.jpg
    - 横1920px程度（それ以上は表示速度のため非推奨）
    - JPEG目安200〜500KB程度に圧縮
    - 明るすぎる写真は文字が読みにくくなるため、
      中央〜下部が比較的暗め・単調な構図がおすすめです
      （文字の可読性を保つ半透明の暗いグラデーションを自動で重ねています）

  representative.jpg
    - 600×600px以上の正方形に近い構図（顔が中央に来るとより綺麗に収まります）
    - JPEG目安150〜300KB程度に圧縮

  ogp.jpg
    - 1200×630px（Facebook/X等の標準サイズ）

背景動画と静止画の優先順位
  - PC/タブレットで背景動画（video/README.txt 参照）が読み込めた場合は、
    動画が優先して表示されます。
  - 動画が無い場合、読み込めない場合、またはスマートフォン／
    データ節約モード／モーション低減設定の場合は、
    ここで置いた hero-poster.jpg が表示されます。
  - それも無い場合は、現在の黒×ゴールドの背景デザインが表示されます。
