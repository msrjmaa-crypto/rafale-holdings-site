背景動画の設置方法
====================

【現在の状態】このフォルダには動画ファイルがまだ置かれていません。
そのため、トップページのファーストビューには「コード生成のオープニング
ムービー（黒背景→桜→ゴールドの光→ロゴ→タグライン、HTML/CSS/JSのみ・
約12秒ループ）」が表示されています。これは壊れているのではなく、動画が
未設置のときに自動的に表示される、完成された代替演出です。
（localhost等での開発時のみ、画面右下に「背景動画 未設置」の案内が
小さく表示されます。本番ドメインでは表示されないため、動画を最後まで
設置しない場合でも本番サイトに開発用の注意書きが残ることはありません。
動画を設置すると、この案内は自動的に消えます）

このフォルダに以下のファイル名で動画を置き、index.html の <video> に
data-hero-video を足すと、実写の背景動画に切り替わります。

  assets/videos/rafale-opening.mp4   … 必須
  assets/videos/rafale-opening.webm  … 任意（対応ブラウザで優先され、ファイルサイズを抑えられます）

  index.html（HEROの中）:
    <video class="hero-video" id="hero-video" data-hero-video muted loop playsinline ...>
                                              ~~~~~~~~~~~~~~ これを足す

  ※ 以前は目印なしで読み込みを試みていたため、動画が未設置のあいだ
     PC表示のたびに 404 が2件出ていました。目印を付けたときだけ
     読みに行くようにしてあります。

動画は以下の状態で自動再生されます。
  ・音声なし（muted）
  ・自動再生（autoplay、JS経由で確実に開始）
  ・ループ再生（loop）
  ・インライン再生（playsinline。iOSでも全画面化せずその場で再生）

ファイルが無い場合や読み込みに失敗した場合は、img/hero-poster.jpg
（設置していれば）、それも無ければ上記のコード生成ムービーが自動的に
表示され続けます。レイアウトが崩れることはありません
（index.html / css/style.css の変更は不要です。画像の設置方法は
img/README.txt を参照）。

推奨スペック（表示速度を落とさないための目安）
  - 長さ: 10〜20秒程度のループ
  - 解像度: 1920×1080以下（4Kは不要）
  - 音声トラック: 無し（あっても再生されません）
  - ファイルサイズ: 3〜6MB程度を目安に圧縮
  - コーデック: H.264 (mp4) / VP9 (webm)

トリミングについて
  - どんな縦横比の動画を置いても object-fit: cover でファーストビュー
    いっぱいに自動トリミングされます。文字やボタンの位置がずれることは
    ありません。

黒い半透明オーバーレイについて
  - 動画の上には文字を読みやすくするための暗いグラデーション
    （.hero-shade）が自動的に重なります。動画が明るい場合でも
    見出し・タグラインの可読性が保たれます。

PC・スマートフォンでの挙動について
  - PC/タブレットでは動画が画面いっぱいに表示されます。
  - スマートフォン（画面幅769px未満）では動画を一切読み込みません。
    img/hero-poster.jpg を置いていればその画像が、無ければコード生成
    ムービーが「軽量な代替表示」として表示されます
    （動画をスマホでも使いたい場合は、開発者にご相談ください。
    軽量な別ファイルを用意すれば専用の切り替えを追加できます）。
  - OS側で「データ節約モード」が有効な場合も同様に動画を読み込みません。
  - OS側の「視差効果を減らす／モーション低減」設定が有効な場合も、
    動画の自動再生・桜演出・コード生成ムービーのループがすべて
    停止（静止表示）します。

差し替え・変更したい場合
  - ファイル名を変える場合は js/script.js 内の
    "assets/videos/rafale-opening.mp4" / ".webm" の記述を
    合わせて変更してください。


====================
オープニングムービー 制作ブリーフ（rafale-opening.mp4 用）
====================

タイトル
  Rafale Holdings株式会社 Corporate Opening Movie

動画時間
  約12秒（自然にループ）

構成
  0〜3秒
    黒を基調とした高級感のある空間。
    背景には和紙を思わせる繊細な質感。
    桜の花びらがゆっくり舞い始める。

  3〜7秒
    柔らかな金色の光が画面中央へ流れ、
    上品な粒子が静かに漂う。

  7〜9秒
    Rafale Holdings のロゴがゆっくりフェードイン。

  9〜12秒
    "Driven by Joy. Growing People. Growing Businesses." を表示。
    約3秒静止し、そのまま自然にループ。

色味
  ブラック / ゴールド / ホワイト

世界観
  ・Appleのようなミニマルデザイン
  ・高級ホテルのブランドムービー
  ・日本らしい上品さ
  ・企業としての信頼感
  ・落ち着いた雰囲気
  ・シネマティック
  ・4Kクオリティ（納品時は上記スペック欄の目安まで圧縮してください）

補足
  サイト側にはすでに桜の花びらが舞う軽量演出（CSS/JS）と、この構成を
  再現したコード生成のオープニングムービーが実装済みです。実写動画を
  制作する場合は、同じ構成美をそのまま実写に置き換える形になります。
